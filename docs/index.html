多个隔离的浏览器身份

Browser Sandbox Manager 让你用独立的 --user-data-dir 并排启动多个 Chrome / Edge 配置，每个配置拥有独立 Cookie、会话、扩展与代理。 适合多账号管理、工作 / 个人分离，以及带代理的测试。

核心功能

🧩

多浏览器支持

自动检测 Windows / macOS / Linux 上的 Chrome 与 Edge 可执行文件。

🔒

完全隔离

每个配置使用独立 --user-data-dir，Cookie、会话、扩展互不干扰。

🏷️

自定义角标图标

在浏览器真实图标上绘制文字角标（最多 4 字符），Windows 任务栏一眼区分。

🗂️

配置分组

按项目或用途组织配置，每个分组拥有独立颜色标识。

🌐

代理支持

为每个配置单独设置代理（http / https / socks5，可选账号密码）。

💾

会话快照 & 导入导出

记忆已打开的配置，并可将整套配置导出 / 合并导入到其他机器。

🌏

中英双语

内置中文与英文界面，选择会本地保存。

🌙

现代深色界面

基于 React + TailwindCSS 打造的清爽深色 UI。

工作原理

1

为配置创建专属数据目录 profiles/<uuid>/。

2

启动浏览器时传入 --user-data-dir 与可选 --proxy-server。

3

每个浏览器作为独立进程运行，状态完全隔离。

4

Windows 上通过 Win32 API 将带角标的图标写入窗口任务栏。

安装与构建

从源码构建

前置条件：Node.js 18+、Rust、Tauri v2 依赖。

git clone https://github.com/456wyc/browser-sandbox.git
cd browser-sandbox
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 生产安装包

快速使用

  1. 点击 新建配置。
  2. 选择浏览器类型（Chrome / Edge）。
  3. 设置角标（如 A1、Work）。
  4. 可选：分组、默认网址、代理。
  5. 点击 启动 打开隔离浏览器。
